# Rice components

## Verified system

The audit was performed on 2026-08-27 through read-only host commands. The host identifies itself as EndeavourOS with kernel `7.1.9-arch1-2`. The active session exported `XDG_SESSION_TYPE=wayland` and `XDG_CURRENT_DESKTOP=KDE`. Plasma and KWin both reported 6.7.4.

The primary desktop's ClearClock snapshot also references `ZinHenaBokuryu`, `ZinHenaKaede-RKF` and `YAKITORI`. These user-local font files are not redistributed: the authoritative source and redistribution terms for both ZinHena faces could not be verified, while YAKITORI requires its own license review at <https://www.mksd.jp/yakitori.html>. ClearClock falls back to an available font until you supply licensed copies or choose replacements.

The third-party projects are not vendored. Install them from their upstream sources:

- [Klassy](https://github.com/paulmcauley/klassy)

## Panels

The live setup contains four floating panels for two screens.

Primary screen:

1. Bottom, 980×46: Kickoff → Icons-only Task Manager → margin separator → System Tray → Digital Clock → Show Desktop.
2. Top, 1040×28: Kara → expanding spacer → KVitals → Network → Volume → Battery → Digital Clock.

Secondary screen:

1. Bottom, 620×40: Kickoff → Icons-only Task Manager → Digital Clock.
2. Top, 760×27: Kara → expanding spacer → KVitals → Network → Volume → Battery → Digital Clock.

Third-party widgets:

- [Kara 1.0.0](https://github.com/dhruv8sh/kara) — virtual desktop switcher.
- [KVitals 3.1.1](https://github.com/yassine20011/kvitals) — CPU/RAM and other metrics.
- [ClearClock 0.3](https://github.com/qewer33/ClearClock) — configured on the primary desktop, not in the top panel.

Kara uses the QML search paths captured in `rice/config/kde/kara.sh`. The small environment script is included; the arbitrary user-local QML libraries it points to are not copied.

## Workspaces

KWin is configured with seven desktops in one row. `kglobalshortcutsrc` maps `Alt+1` through `Alt+7` to direct desktop switching. The repository ships only those seven lines in `kglobalshortcutsrc.snippet`; the installer merges them instead of replacing all global shortcuts.

## KWin and composition

- Blur enabled, strength 8, noise 1.
- Translucency enabled; menus are 78%, dialogs 94%, move/resize 90%.
- Scale transition 180 ms.
- Overview transition 200 ms.
- Slide effect has zero horizontal/vertical gaps.
- ShapeCorners / KDE Rounded Corners enabled.
- Klassy titlebars: active 76%, inactive 58%, 10 px radius and contrast outline.

These values favour usability and restrained depth rather than heavy glass effects.

## Terminal and Fastfetch

Ghostty 1.3.1 uses Agave Nerd Font 14, a `#0d0c0d` background at 86% opacity, blur, 14×12 padding and a custom mauve palette. Fastfetch 2.67.1 uses the built-in EndeavourOS logo recolored in rose/mauve/violet plus hardware, software and miscellaneous sections. Hardware-dependent results are generated by Fastfetch at runtime and are not committed.
