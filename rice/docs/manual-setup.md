# Manual setup

Use this route when you do not want scripts to write KDE configuration.

1. Install packages from `manifest.json`.
2. Copy `rice/assets/wallpapers/Mauve_girl.webp` to a stable path under `~/.local/share/wallpapers/desktop-dream/`.
3. In System Settings → Colors & Themes select Breeze Dark, Darkly, Ant-Dark, Reversal, macOS-White and Klassy.
4. Set FantasqueSansM Nerd Font 10 for general/menu/toolbar text, Agave Nerd Font 12 for fixed width text and Inter 10 for active titles.
5. In Window Decorations choose Klassy. Configure 10 px radius, active/inactive titlebar opacity 76/58, large shadow and a 1 px contrast outline.
6. In Desktop Effects enable Blur, Translucency, Scale, Slide, Overview and Rounded Corners. Use the values in `config/kwin/kwinrc`.
7. Create seven virtual desktops in one row. In Shortcuts → KWin map direct switching to `Alt+1` … `Alt+7`.
8. Create a top floating panel and add Kara, an expanding spacer, KVitals, Network, Volume, Battery and Digital Clock.
9. Create a bottom floating panel and add Kickoff, Icons-only Task Manager, System Tray, Digital Clock and Show Desktop.
10. Add ClearClock to the primary desktop. The snapshot references `ZinHenaBokuryu`, `ZinHenaKaede-RKF` and `YAKITORI`; use licensed copies or select available substitutes because these fonts are not redistributed.
11. Copy the Ghostty and Fastfetch files after backing up your existing versions.

Panel lengths in the captured dual-screen setup are 1040×28 and 980×46 on 1920×1080, plus 760×27 and 620×40 on 1366×768. Scale them proportionally on different screens; usability is more important than exact pixels.
